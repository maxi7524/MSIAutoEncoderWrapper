# How-to guides

These guides describe how to perform specific operations with the public
library interface. They document accepted inputs, relevant options, validation,
and result verification.

## Contents

- [Workspace and contexts](workspace-and-contexts/index.md) — create a workspace and select single-image or cohort contexts.
- [Data input and preprocessing](data-input-and-preprocessing/index.md) — configure readers, binning, normalization, and molecular annotations.
- [Models and training](models-and-training/index.md) — configure datasets, architectures, training, and model artifacts.
- [Experiment execution](experiment-execution/index.md) — define and run repeatable local or Slurm experiments.
- [Analysis](analysis/index.md) — current status and supported analysis entry points.
- [Dataset management](dataset-management/index.md) — discover, download, annotate, import, and merge external datasets.
